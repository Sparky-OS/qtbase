## Sparky Stereo OS

This is Sparky Stereo OS's stereo work on Qt® Base, forked from [qt/qtbase](https://github.com/qt/qtbase).
It adds stereo windows on Wayland, with EGL surfaces of two views, and a stereo QOpenGLWidget.
It reads the stereo layout of PNG `sTER` and marked JPEG pictures.
A translucent window keeps the colour depth it asks for.

Where it comes from:

- [Qt](https://www.qt.io/) is made by The Qt Company and the contributors of the Qt Project.
- [Debian](https://www.debian.org/) is the base of the system.
- [SparkyLinux](https://sparkylinux.org/), by Paweł "pavroo" Pijanowski, builds on Debian.
- [Sparky Stereo OS](https://github.com/Sparky-OS/sparky-stereo-os) is the stereo 3D edition of SparkyLinux: SparkyOS, powered by Debian.
